# 🌍 Open Source Journey

Welcome to my **Open Source Journey!**

This repository documents my journey of learning, exploring, and contributing to the open-source community.

I created this repository to understand how open-source projects work, strengthen my Git and GitHub skills, collaborate with developers, and make meaningful contributions to real-world projects.

Rather than just learning concepts, I believe in practising them and documenting my progress along the way.

## 🎯 Goals

- Understand the open-source ecosystem and how it works.
- Learn Git and GitHub workflows.
- Explore beginner-friendly open-source projects.
- Understand issues, branches, commits, and pull requests.
- Make meaningful contributions to real-world projects.
- Improve collaboration, communication, and problem-solving skills.
- Track my learning progress and contributions.
